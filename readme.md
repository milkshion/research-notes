### Vim 编辑器基础与保命指南

- 核心概念：Vim 是基于“模式”的编辑器，不同模式下按键功能不同
  - `普通模式`：默认模式，按键是快捷键（如 dd 删除行、yy 复制行）
  - `插入模式`：按 `i` 进入，此时可以像普通文本一样打字
  - `命令模式`：按 `:` 进入，用于保存、退出等操作
- 保命四连（新手的终极逃生舱）：
  - `vim 文件名`：打开或新建文件
  - `i`：进入插入模式（打字）
  - `Esc`：退出插入模式（回到普通模式）
  - `:wq`：保存并退出
  - `:q!`：不保存，强行退出（改乱了就按这个）
- 进阶操作（在普通模式下使用）：
  - `dd`：删除（剪切）光标所在行
  - `u`：撤销上一次操作
  - `yy`：复制光标所在行
  - `p`：粘贴到光标下一行
  - `gg` / `G`：跳转到文件首行 / 尾行
