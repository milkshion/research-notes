## Day 1
- 学会了基本的 Linux 命令
  - `pwd`：显示当前路径
  - `mkdir`：创建一个文件夹（目录）
  - `cd`：进入一个文件夹
  - `touch`：创建空文件（或更新文件时间）
  - `cp`：复制文件（用法：`cp 源文件 目标文件`）
  - `mv`：移动或重命名
    - 重命名：`mv 旧名字 新名字`
    - 移动：`mv 文件名 目标文件夹路径`
    - 移动并改名：`mv 旧名字 目标文件夹路径/新名字`
  - `echo`：写入内容（用法：`echo "内容" > 文件名`）
  - `cat`：查看全部内容
